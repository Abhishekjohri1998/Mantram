## Lessons Learned
- **Required Inputs on Blocked Nodes:** Required input ports (e.g. `image_in` on `image_to_3d` with `required: true`) must be populated in test configurations or params, otherwise the validation engine halts before execution reaching the handler block. Supplying a dummy URL param satisfies the constraint and cleanly triggers the provider error.
- **Dynamic Registry Affordance:** Derive frontend categorizations directly from backend registries to eliminate sync overhead.
